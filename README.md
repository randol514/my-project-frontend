# 🍋 Little Lemon – Reserve a Table

Aplicación web desarrollada en React para gestionar reservas de mesa en el restaurante Little Lemon.

## 📦 Repositorio

https://github.com/randol514/my-project-frontend

---

## 🧩 Descripción

Este proyecto permite a los usuarios seleccionar una fecha, hora y número de personas para reservar una mesa.  
Incluye validación de formularios, manejo de estado y simulación de una API.

---

## 🛠️ Tecnologías utilizadas

- React
- React Router
- JavaScript (ES6+)
- CSS
- Testing Library (Jest + React Testing Library)

---

## ⚙️ Funcionalidades

- 📅 Selección de fecha con validación
- ⏰ Horarios dinámicos (simulados con API)
- 👥 Selección de número de invitados
- 🎉 Selección de ocasión (Birthday, Anniversary)
- ✅ Validación de formularios (HTML5 + lógica en React)
- 🚫 Botón deshabilitado si el formulario es inválido
- 📡 Simulación de envío con API (`submitAPI`)
- 🔄 Manejo de estado con `useReducer`
- 🧪 Testing de componentes

---

## 🧠 Conceptos aplicados

- State lifting (estado elevado)
- Controlled components
- Manejo de eventos en React
- Validación de formularios
- Testing de UI
- Simulación de APIs
